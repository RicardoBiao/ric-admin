# RicTV - 视频播放器应用

一个现代化的视频播放器应用，支持 MacCMS v10 API 视频源，使用 ArtPlayer + HLS.js 作为播放内核。

**✨ 全新特性：完整支持 PC 端和移动端！**

## ✨ 功能特性

- 🎬 支持多视频源管理 (MacCMS v10 API)
- 🎨 现代化 UI 设计，支持深色主题
- 📱 响应式布局
  - **移动端**: 底部固定导航栏，2-3列网格
  - **PC 端**: 顶部导航，4-6列网格
- 🔍 视频搜索功能（支持筛选过滤）
- ❤️ 收藏功能（使用 localStorage 本地缓存）
- 📺 基于 ArtPlayer + HLS.js 的视频播放
- ⏯️ **观看历史记录**
- 🎯 **断点续播功能**
  - 自动保存播放进度（每5秒）
  - 继续观看提示
  - 播放进度百分比显示
- 🌙 深色主题 + 渐变背景
- 💻 接口数据支持缓存（首页数据、详情数据等），超过 20MB 自动清理

## 🛠️ 技术栈

- **前端框架**: Vue 3 (Composition API)
- **构建工具**: Vite 7
- **UI 组件库**: Radix Vue + 自定义组件
- **样式**: Tailwind CSS 4
- **路由**: Vue Router 4
- **状态管理**: VueUse + Composables
- **播放器**: ArtPlayer 5.3.0
- **流媒体**: HLS.js 1.6.15
- **包管理**: Pnpm 9
- **语言**: TypeScript 5.8


## 🔧 使用说明

### 添加视频源

1. 打开应用,进入"我的"页面
2. 点击右上角"+"按钮
3. 填写视频源名称和 MacCMS v10 API 地址
   - 例如: `https://example.com/api.php/provide/vod/`
4. 点击保存

### 观看历史与断点续播

1. **自动记录**：观看视频时会自动记录到历史
2. **断点续播**：重新打开视频详情页时，如果有观看记录会显示"继续观看"提示
3. **查看历史**：在"我的"页面点击"查看全部"按钮进入完整历史记录页面
4. **播放进度**：
   - 每5秒自动保存一次播放进度
   - 显示已观看百分比
   - 支持"继续播放"和"从头开始"两种选择
5. **管理历史**：
   - 长按或点击删除按钮可删除单条记录
   - 点击"清空"按钮可清空所有历史记录

### MacCMS v10 API 格式

视频源需要支持 MacCMS v10 标准 API 格式:

```
# 获取分类列表
GET /api.php/provide/vod/?ac=list

# 获取视频列表
GET /api.php/provide/vod/?ac=detail&pg=1

# 搜索视频
GET /api.php/provide/vod/?ac=detail&wd=关键词

# 获取视频详情
GET /api.php/provide/vod/?ac=detail&ids=视频ID
```
