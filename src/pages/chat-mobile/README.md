# Chat 聊天系统 - PC 端 vs 移动端

## 页面对比

### PC 端（客服端）- `/chat`

**特点：**
- 左侧会话列表 + 右侧聊天窗口的分屏布局
- 可以同时管理多个会话
- 搜索和筛选会话
- 完整的聊天功能

**页面结构：**
```
┌─────────────────────────────────────┐
│     消息列表        │    聊天窗口    │
│   ┌─────────────┐   │  ┌──────────┐ │
│   │ 张三 14:30  │   │  │ 张三对话 │ │
│   │ 李四 12:15  │   │  │ 消息列表 │ │
│   │ 王五 10:45  │   │  │ 和输入框 │ │
│   │ 赵六 昨天   │   │  │          │ │
│   └─────────────┘   │  └──────────┘ │
└─────────────────────────────────────┘
```

**功能：**
- ✅ 会话列表（搜索、未读数、最后消息）
- ✅ 聊天界面（消息、输入框）
- ✅ 表情、图片、文件支持
- ✅ 已读状态显示

**路由：** `/chat`

---

### 移动端（用户端）- `/chat-mobile`

**特点：**
- 全屏聊天界面
- 只显示一个对话
- 简洁的顶部导航
- 适配小屏幕设备

**页面结构：**
```
┌──────────────────────┐
│ ← 客服         在线  │  <- 顶部导航
├──────────────────────┤
│                      │
│   消息列表           │
│                      │
├──────────────────────┤
│ 输入框和功能按钮     │
└──────────────────────┘
```

**功能：**
- ✅ 顶部导航（返回、会话名、在线状态）
- ✅ 聊天界面（消息列表）
- ✅ 输入框（表情、图片、文件）
- ✅ 已读状态显示
- ✅ 自适应高度调整

**路由：** `/chat-mobile`

---

## 组件复用

两端都复用以下组件：

### 消息组件
- `ChatMessage.vue` - 消息容器
- `ChatBubble.vue` - 气泡
- `ChatTextContent.vue` - 文本内容
- `ChatImageContent.vue` - 图片内容
- `ChatFileContent.vue` - 文件内容
- `ChatTimestamp.vue` - 时间戳
- `ChatImagePreview.vue` - 图片预览

### 输入组件
- `ChatInputBox.vue` - 输入框（包含表情、图片、文件功能）

## 核心区别

| 功能 | PC 端 | 移动端 |
|------|------|--------|
| 会话列表 | ✅ 显示 | ❌ 不显示 |
| 聊天界面 | ✅ 右侧 | ✅ 全屏 |
| 搜索功能 | ✅ 有 | ❌ 无 |
| 同时管理多会话 | ✅ 支持 | ❌ 单个对话 |
| 输入框 | ✅ 完整 | ✅ 完整 |
| 表情支持 | ✅ 是 | ✅ 是 |
| 图片/文件 | ✅ 是 | ✅ 是 |
| 已读状态 | ✅ 显示 | ✅ 显示 |

## 使用场景

### PC 端（`/chat`）
- 客服人员管理多个客户对话
- 需要快速切换不同的客户
- 查询和搜索历史对话
- 批量处理多个会话

### 移动端（`/chat-mobile`）
- 客户在手机上与客服沟通
- 单个、专注的对话体验
- 响应式设计，适配各种屏幕尺寸
- 简洁易用的界面

## 开发指南

### 添加新功能

如果要添加所有两端都需要的功能（如新消息类型）：
1. 在 `ChatMessage.vue` 或相关子组件中修改
2. 两端会自动继承新功能

### 仅 PC 端功能

直接修改 `ChatLayout.vue` 中的 PC 端特定代码

### 仅移动端功能

直接修改 `chat-mobile/index.vue` 中的移动端特定代码
